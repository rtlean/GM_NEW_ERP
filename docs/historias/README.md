# Histórias de Usuário — Fatias 0 a 6 (MVP)

## Como usar com o Claude Code
Copie o prompt abaixo trocando o ID da história:

```
Leia CLAUDE.md, docs/02-TRD.md e a história US-3.2 em docs/historias/fatia-3-cadastros.md.
Mostre o plano (telas em src/app, regras em src/lib, testes) antes de escrever código.
Trabalhe na branch feat/us-3.2. Ao final: testes passando, roteiro de teste manual e PR.
```

## Formato
- **Como** [perfil] **quero** [ação] **para** [benefício]
- **Critérios de aceite** em Dado / Quando / Então (viram testes)
- **Tamanho:** P (até 1 sessão), M (2–3 sessões), G (dividir antes de começar)
- **Depende de:** histórias que precisam estar prontas
- ⚠️ **Bloqueio de decisão:** pendência do PRD que precisa de resposta antes de finalizar
